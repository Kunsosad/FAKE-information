# Profile Specification

## Overview
- Target: personal information view in `GPA.html`.
- Reference: user-provided desktop screenshots.
- Interaction: static fields and local tab state.

## Layout
- Grey section headers, blue active tab, compact label/input grid.
- Desktop uses three field columns beside a portrait placeholder.
- Mobile collapses to one column.

## Security
- Personal data stays in local JavaScript.
- The Office365 initial password is masked and is not stored in source.
