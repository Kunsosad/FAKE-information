# Page Topology

- Shared masthead: official logo image.
- Shared navigation: Personal dropdown, five source navigation items, student greeting, logout label.
- Profile view: personal, academic, family, residence, and emergency fields.
- GPA view: semester summary, graduation conditions, foreign-language certificates, 38-row grade table.
- Tuition view: semester control, deferral form, 10-row tuition table, payment history, balance table.
- Interaction model: Personal dropdown opens on hover/focus; Profile, Tuition, and GPA entries switch local views.
- Responsive model: source desktop layout is preserved and scrolls horizontally on narrow screens.
